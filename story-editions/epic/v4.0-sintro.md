# 第四章第一至二幕：白露与黑潮的序诗；仿若无因飘落的轻雨

枫丹以审判为公共生活的中心。旅人来到这里，见水神芙宁娜在人前登台，伴随喝彩；最高审判官那维莱特则沉静地主持法庭。街头流传着古老预言：海水将上涨，枫丹人尽数溶解，唯有水神独坐神座，流泪到最后。

林尼与妹妹琳妮特接待了来客。一场公开魔术忽生变故，有人殒命，有观众失踪，林尼被控借魔术杀人。旅人走上辩护席，循舞台机关追查，揭出有人利用「原始胎海之水」犯罪，替他洗清罪名。审理也揭开了兄妹所属的愚人众组织——「壁炉之家」。两人的隐瞒，让这段相识生出了隔阂。

娜维娅随后与旅人一道追查多年女性连环失踪案。她的父亲卡雷斯曾背负罪名而死，她要还父亲清白。线索终至商人瓦谢：他以胎海之水溶解受害者，妄想寻回消失的爱人。水中传来被害者的声音，旧罪终于昭然，卡雷斯的冤屈也得以洗去。旅人由此确认，枫丹人确会在胎海之水中溶解。

公子也因这桩连环案受审。那维莱特判他无罪，谕示裁定枢机却宣告有罪。公子起身反抗，被那维莱特制服，送往梅洛彼得堡。法官与枢机何以得出相反的裁决，仍无人能够说明。
