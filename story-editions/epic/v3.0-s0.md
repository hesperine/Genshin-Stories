# 同期世界支线：森林书

拉娜受死域侵蚀，旅人为救她，与森林中的兰那罗相识。众人收集孕育惟耶之实所需的回忆，深入森林，对抗「无留陀」。

兰罗摩耗尽记忆与力量，化为新的觉王之树。兰拉娜以惟耶之实唤醒拉娜，也失去了与她相处的往事。拉娜获得神之眼，决定与兰拉娜一同远行。往日的回忆已经散去，两人还将沿途，重新积攒共同的记忆。
