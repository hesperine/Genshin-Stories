# 第一幕：无神怜爱的雪国

### 风雪中的来客

离开挪德卡莱时，哥伦比娅前来送行。旅人与派蒙一路向北，终于抵达七国中的最后一国。至冬风雪未歇，派蒙已愈发虚弱；狂风又将两人冲散。旅人跌入深谷，在废弃列车旁唤醒古老装置「灰眸」。它认出降临者，以日后相助为约，借臻冰造物的力量，带旅人穿过险境。

雪屋中，派蒙昏睡未醒，一个有着坎瑞亚星瞳的陌生人守在身旁。他不答身份，也不说与派蒙有何旧缘，只请旅人先照料她，便消失在风雪里。派蒙醒来，认出那是愚人众统括者「丑角」皮耶罗，却想不起彼此曾有何交集。觐见女皇的事暂且搁下，旅人先为同伴求医。

灰眸驱动旧列车，将两人载到凝露镇。晶矿短缺，店铺闭门，居民难以取暖。猎人阿罗夏收留派蒙，也让旅人见到严冬计划下的日常。冰之女皇压缩民间能源，集中力量推进重要研究，地方官却又借分配之机私藏晶矿。旅人与阿罗夏搜得证据，使贪墨者被捕，居民终于取回本该属于自己的燃料。

去往皇都的列车忽然坠入影域。那里少了风与光，也缺乏寻常元素力。灰眸为旅人重整装备，助众人击退魔物，返回地面。

### 皇都与严冬计划

列车驶入至冬堡。医生暂将派蒙的病归于受寒，药物却未能尽除虚弱。旅人向愚人众寻访，得知公子达达利亚还须代表属下，出席至冬皇都评议会。桑多涅虽不愿深陷政事，仍带旅人前往彩冰镇救援矿工。

矿洞崩塌，旅人与愚人众成员奥黛塔并肩迎击魔物。一股新的力量在掌中凝成剑。其后，旅人来到冰之七天神像前，终于与冰元素共鸣。

阿罗夏又将来客引至呼啸社。成员隐身寻常职业，追查权势之人浪费、挪用能源的行迹。歌者沃雅妮莎居中牵线，让旅人见到研究者米提亚。军械宫的实验正大量耗费晶矿，要从星之楔中寻得新能源；研究者却接连失忆。米提亚将要说出最终用途，颈间异物忽然阻断话语。派蒙也感到，军械宫方向有力量牵动自己。

评议会上，普契涅拉以全国用能为据，坚持推进计划；达达利亚质问偏远地区与愚人众家属为何所得更少，潘塔罗涅则以维系大局回应。投票以微弱优势让计划延续。

暗中活动的莱莱可，正以潜入与威胁迫使权贵投下反对票。桑多涅与达达利亚怀疑，她便是奥黛塔：父亲死于计划早期，母亲也从此无法登台。旅人持公子的票走向剧院，要在芭蕾试演之后，当面问清她的选择。
