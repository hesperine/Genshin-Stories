# 序章第二幕：为了没有眼泪的明天

风暴中的巨龙名为特瓦林，昔日曾为蒙德守望。骑士团愿将它从灾厄中救回，至冬的愚人众外交官却主张杀龙。旅人带回的泪滴结晶，会灼伤借神之眼引导元素的人；旅人却能亲手将它净化。吟游诗人温迪由此看见了救龙的希望。

毒血侵蚀着特瓦林，深渊教团又在它心中种下被背弃的猜疑。温迪想借旧日的「天空之琴」，唤回巨龙的记忆。众人前去取琴，愚人众却抢先将它盗走，旅人与诗人反成了蒙冤的窃贼。晨曦酒庄的迪卢克暗中接应，琴暂放下代理团长的身份，也加入这场奔忙。

天空之琴被夺回，净化的龙泪使琴弦重得风的力量。众人登上摘星崖，以琴声唤来特瓦林。旧曲将续，深渊法师却骤然现身，再度挑起龙的猜忌。特瓦林唤出「巴巴托斯」之名，质问风神为何带人前来猎杀自己。

诗人的身份终于在同伴面前显露，古琴却在混乱中受损，巨龙也已远去，飞向结界封锁的旧蒙德遗迹。风里再无琴声，众人仍须追寻。
