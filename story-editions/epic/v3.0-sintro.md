# 第三章第一至二幕：穿越烟帷与暗林；千朵玫瑰带来的黎明

雨林中的一缕异香，使旅人陷入昏迷，也窥见与世界树相连的异象。巡林官提纳里与见习巡林员柯莱将来客带回道成林照料。柯莱自幼患魔鳞病，求医时落入愚人众之手，曾被博士的手下用于魔神残渣实验。她逃至蒙德，得到安柏相助，后来由赛诺封印体内残力，带回须弥。如今，她随提纳里学习，病情也由老师照料。

须弥人借虚空终端求取知识，却似乎很少做梦。旅人进城求见小吉祥草王纳西妲，才知这位现任神明长久不受教令院尊重。花神诞祭将至，妮露仍坚持为她献舞。

节日来临，节日过去，旅人却一次次在同一个清晨醒来。对话似曾听闻，细节渐生错位，疲惫不断积累。纳西妲在梦中守住旅人的记忆，两人循着循环查明，教令院正借虚空收割民众的梦境。城中人困在同一日，身体也在一日又一日的梦中衰弱。

妮露是这场梦的主人。旅人让她认出身在梦中，她唤出盛开的帕蒂沙兰，终于跳完献给草神的舞。循环瓦解，濒危的迪娜泽黛也被纳西妲救下。

梦境散后，纳西妲借凯瑟琳的身体与旅人在现实中相谈。草神本人的囚居，却仍在净善宫中延续。
