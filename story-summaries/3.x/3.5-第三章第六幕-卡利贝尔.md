# 3.5｜第三章第六幕：卡利贝尔

戴因斯雷布在须弥再度现身。凯亚偶然谈及自己的姓氏——亚尔伯里奇——使坎瑞亚的旧影逼近。旅行者随后陷入一段与血亲的记忆相连的经历，见到坎瑞亚贵族克洛达尔·亚尔伯里奇和他的儿子卡利贝尔。父亲是不死的受诅咒者；儿子已变成丘丘人，仍被父亲珍爱。克洛达尔不肯接受儿子只能慢慢失去自我，四处求取能解除诅咒的方法。

他在神秘晶体前听见自称「罪人」的声音。声音带来超出常理的力量与希望，也诱使绝望中的父亲把救赎寄托在未知存在身上。卡利贝尔短暂显出变化，却没有在旅行者眼前迎来明白无误的结局。克洛达尔后来与深渊教团的起源联系在一起。旅行者醒来后才意识到，自己所经历的并非普通的当下调查，而是血亲曾走过的往事。

坎瑞亚的灾难至此有了父与子的面孔。深渊教团的诞生不只是一个反神口号，也来自活生生的人在诅咒面前不肯放手的悲痛；但「罪人」究竟是什么，仍无人能给出可靠答案。
