# 3.3｜间章第三幕：倾落伽蓝

散兵战败后留在须弥。旅行者陪他进入世界树，他在那里读到自己作为雷神造物、被遗弃者与愚人众执行官的过去，也读到踏鞴砂悲剧背后的欺骗。他以为自己只给他人带来不幸，便试图从世界树里抹去「散兵」的存在，好让受害者获得另一种人生。

世界的记忆确实改写了：人们不再记得散兵，相关故事也找到了新的解释。然而旅行者亲自查证后发现，已经发生的死亡并未倒转。抹掉名字能改变人们如何叙述过去，不能让过去未曾发生。一个失去记忆的青年游荡在须弥，纳西妲则把散兵的往事藏成寓言，让他有机会重新面对自己。

旅行者把真相还给青年。他选择取回记忆，承认过去所犯的事，也不再任由旧身份替自己决定未来。纳西妲收留他，旅行者为他起了新名字——流浪者。此刻的他不因赎罪便自动获得宽恕，却终于能以自己的意志承担后果。
