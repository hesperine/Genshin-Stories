# 3.3｜间章第三幕：倾落伽蓝

散兵战败后留在须弥。旅行者陪他进入世界树，他在那里读到自己作为雷神造物、被遗弃者与愚人众执行官的过去，也读到踏鞴砂悲剧背后的欺骗。他以为自己只给他人带来不幸，便试图从世界树里抹去「散兵」的存在，好让受害者获得另一种人生。

旅行者再次查访踏鞴砂，发现死者仍已死去，记录却将他们的遭遇归于其他缘由；人们也忘记了散兵。须弥街头则出现一个与他相貌相同、失去旧日记忆的青年。纳西妲早将散兵的往事写成寓言，避过世界树的改写，如今可以借它让青年了解自己的过去。

青年选择取回记忆，在面对过去时获得风元素神之眼。纳西妲留他在须弥，旅行者受托为他起了新的名字。他以流浪者的身份留下，也请旅行者将自己所犯的事告诉受害者的后人。
