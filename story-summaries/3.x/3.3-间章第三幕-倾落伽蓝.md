# 3.3｜间章第三幕：倾落伽蓝

散兵战败后留在须弥，旅行者陪他进入世界树，查阅旧日记忆。他是雷神早年造出的人偶，离开神明后，曾被踏鞴砂的丹羽等工匠接纳。后来，博士化名工匠埃舍尔，借新冶炼技术激发矿石中的邪祟，引发炉心灾难。他杀害丹羽，把丹羽的心脏放入装置，交给散兵带进炉心清除污秽，又谎称丹羽杀死随从、畏罪潜逃，让散兵将这段往事记作朋友的背叛。

受骗的恨意曾使散兵向稻妻的锻刀家族复仇，伤及无辜。如今真相显露，他希望那些死在踏鞴砂、与自己有关的人能获得另一种人生，便试图从世界树里抹去自身的存在。

旅行者再次查访踏鞴砂，发现死者仍已死去，记录却将他们的遭遇归于其他缘由；人们也忘记了散兵。失去旧日记忆的散兵仍在须弥，以流浪青年的身份生活。纳西妲早将他的往事写成寓言，避过世界树的改写，如今可以借它让青年了解自己的过去。

青年选择取回记忆，在面对过去时获得风元素神之眼。纳西妲留他在须弥，旅行者受托为他起了新的名字。他以流浪者的身份留下，也请旅行者将自己所犯的事告诉受害者的后人。
