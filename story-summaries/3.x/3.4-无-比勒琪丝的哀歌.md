# 3.4｜无魔神任务：比勒琪丝的哀歌

旅行者再见婕德，随她来到塔尼特部族。主母芭别委派两人深入千壑沙地，寻找永恒绿洲。途中，旅行者与古老的镇灵利露帕尔缔结契约，借她的力量穿过风暴与遗迹。

永恒绿洲中的时间停住，留下赤王、花神与前代草神的旧日痕迹。婕德将父母的遗物留在此处。此后，主母芭别露出利用婕德、清除异己的意图，婕德与旅行者联手反击，最终离开塔尼特部族。
