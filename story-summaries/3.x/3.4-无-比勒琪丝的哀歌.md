# 3.4｜无魔神任务：比勒琪丝的哀歌

> **主线：无。** 本版本延续沙漠世界任务。

旅行者再见婕德，随她回到塔尼特部族，深入风暴覆盖的千壑沙地，寻找传说中的永恒绿洲。传说里的花神遗迹并不能替活着的人解决权力与猜忌；婕德在部族的谋划中一次次失去依靠，最终不得不与曾以为是家的人诀别。

永恒绿洲凝住了极古老的美与哀伤。赤王、花神与前代草神的交往，在壁画和记述里比单一国度的传说更有人性；但再辉煌的旧梦，也救不了当下被利用的人。婕德走出沙海时，不再是那个只需追随父亲的少女。她的命运让旅行者看见，所谓「探索古文明」从来会触及仍活着的后人。
