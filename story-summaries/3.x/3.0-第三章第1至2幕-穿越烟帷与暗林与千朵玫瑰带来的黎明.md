# 3.0｜第三章第一至二幕：穿越烟帷与暗林；千朵玫瑰带来的黎明

旅行者踏入须弥雨林，闻到神秘熏香后陷入昏迷，窥见与世界树相连的异象。巡林官提纳里与见习巡林员柯莱将他们带回道成林照料。柯莱幼时因魔鳞病求医，落入愚人众手中，被愚人众执行官「博士」的手下用于魔神残渣实验；逃到蒙德后得到安柏帮助，担任教令院大风纪官的赛诺又封印了她体内的残留力量，将她带回须弥。如今她师从提纳里，病情也由他照料。旅行者随后得知，须弥人普遍佩戴虚空终端获取知识，却似乎很少做梦。

旅行者进入须弥城，盼见草神小吉祥草王纳西妲，却发现她虽是现任神明，长期不被教令院尊重。身患魔鳞病的迪娜泽黛出资筹办花神诞祭，舞者妮露坚持为草神献舞。节日到了又结束，旅行者却一次次在同一个早晨醒来；熟悉的对话、错位的细节与不断积累的疲惫，证明他们被困在循环里。

纳西妲在梦中帮助旅行者保住每次循环的记忆。两人逐步查明，教令院正在用虚空系统收割民众的梦境，城中居民因此反复经历同一天，身体也不断衰弱。旅行者发现妮露就是当前梦境的主人，便让她意识到自己身在梦中。妮露唤出盛开的帕蒂沙兰，跳完献给草神的舞，循环终于瓦解。纳西妲救下濒危的迪娜泽黛，随后借「凯瑟琳」的身体与旅行者在现实中交谈；她本人仍被困在净善宫。

## 同期世界支线：森林书

为救受死域侵蚀的拉娜，旅行者与兰那罗们相识，收集惟耶之实所需的回忆，并深入森林对抗「无留陀」。兰罗摩耗尽记忆与力量，化作新的觉王之树；兰拉娜用惟耶之实救醒拉娜，也忘记了与她相处的过去。拉娜获得神之眼，决定与兰拉娜一起旅行，重新积攒属于两人的回忆。
