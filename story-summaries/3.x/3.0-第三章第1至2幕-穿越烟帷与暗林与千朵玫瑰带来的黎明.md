# 3.0｜第三章第一至二幕：穿越烟帷与暗林；千朵玫瑰带来的黎明

旅行者踏入须弥雨林，首先闻到能令人失神的神秘熏香，并在昏迷中窥见与世界树相连的异象。巡林官提纳里与见习巡林员柯莱照料了他们。柯莱患有魔鳞病，身体上的鳞片提醒旅行者：须弥的「智慧」并未治愈每一个人。教令院让民众佩戴虚空终端，以神明赐予的系统获取知识；但须弥人似乎也因此不再自然做梦。

旅行者进入须弥城，盼见草神小吉祥草王纳西妲，却发现她虽是现任神明，长期不被教令院尊重。花神诞祭前，舞者妮露坚持为草神献舞。节日到了又结束，旅行者却一次次在同一个早晨醒来；熟悉的对话、错位的细节与不断积累的疲惫，证明他们被困在循环里。

纳西妲以「凯瑟琳」的身体与旅行者接触，帮助他们识破真相：这是由虚空系统抽取民众梦境、反复重演花神诞祭的实验。城市里的人以为自己醒着，实际在一个个被剥夺的梦中消耗。旅行者与妮露一同找到了这场梦的主人；妮露终于在梦中跳完献给草神的舞，循环瓦解。纳西妲救出了众人，却仍没有能力自由走出教令院施加的束缚。

## 同期世界支线：森林书

兰那罗的故事把雨林的危机呈现为另一种语言。旅行者为救拉娜，走入精灵们的记忆与梦，认识侵蚀森林的「无留陀」。兰那罗会为了守护朋友而消耗记忆；他们的温柔并非不知痛苦，而是明知会遗忘，仍愿伸出手。雨林的枯败与人的病症尚未得到完整解释，但「世界的记忆」已成为须弥最重要的谜团。
