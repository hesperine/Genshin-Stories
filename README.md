# 原神主线剧情编年

打开 [剧情阅读器](reader/index.html) 即可按页阅读；无需先安装服务。网页提供白天／夜晚模式、版本与幕目录、翻页、每页预计阅读时长，以及保存在浏览器中的阅读记录。

从 1.0 开始，按版本顺序阅读。每份文档只使用该版本结束时剧情已经公开的信息；文末的「悬而未决」也只记录当时的疑问，不提前给出后续答案。

文档以魔神任务为主线，另收录会改变对提瓦特历史、深渊、七神与古文明理解的重要世界任务或限时剧情。普通节庆、角色日常、玩法更新不逐一收录。任务名称以简体中文为主，必要时附英文检索名。重大剧透均留在所属版本文档内。
