## 检索所得

史诗通常以长篇叙事诗的形式讲述英雄个人或群体的历程。荷马史诗常用反复出现的称谓、程式语和展开的比喻，也有可供传唱的节奏。不同文学传统的具体形式各有区别。[美国诗人学会：Epic](https://poets.org/glossary/epic)

阿诺德在《论翻译荷马》中提出的一种经典读法，尤其适合本项目：故事推进迅疾，语言和意思明白直接，同时保持庄严的气质。这是本次风格选择的参考，并不涵盖所有史诗传统。[《论翻译荷马》原文](https://www.gutenberg.org/cache/epub/65381/pg65381-images.html)

本项目建议采用现代汉语散文，借取这些叙事方法。保留自然段、明确的人名和因果关系，以句子的节奏、意象的呼应和关键事件的分量形成史诗感。

## 已确认的统一风格

| 方面 | 写法 |
| --- | --- |
| 叙述声音 | 像一位讲述旧日行旅与神人往事的人，语气沉着，始终把事情讲下去。 |
| 措辞 | 以自然、准确、便于朗读为准，白话与典雅表达均可随场景选用。连接词按实际语义与节奏取舍；语意已能承接时，可直接转入下一句。 |
| 句子节奏 | 保留自然散文的舒展，长句铺开局势，短句落下转折。在开篇、转折与收束处少量用韵，以关键词和句式的复现形成回环。其余段落自然推进，韵字须贴合情节与语义。 |
| 朗读检视 | 逐段检查主语转换、呼吸停顿与句尾落点。长句的语意应当容易跟随，人物与场景的转移应有自然停顿；每次润色先修局部的拗口与赘余。 |
| 声量与气势 | 交锋、牺牲与历史转折让语势逐步积蓄，在关键动作上落下；归乡、旧宅与告别保留沉静的分量。气势须随场景起伏，韵脚与复沓贴着人物的行动和处境生长。 |
| 校核后的回读 | 新补的身份、背景和机制须融入整段语流。事实修正后，把前后文连起来重新检视，兼看因果是否清楚、停顿是否自然、意象是否连贯、叙述是否仍有韵味。 |
| 意象 | 取自剧情现场：海、山、风、火、祭台、道路、器物。一个场景集中使用一两种。 |
| 人物 | 通过行动、犹疑和实际付出的代价呈现；称谓稳定，人名保留。 |
| 情绪 | 停留在看得见的场面中，把判断留给读者。 |
| 阅读篇幅 | 篇幅随情节密度调整，过场紧凑，重大场面与复杂因果留足必要篇幅。短说明与悬念页保持简洁，阅读器按正文每分钟约 400 字估算时长。 |

事实、事件顺序、人物立场和每个版本当时已揭晓的信息，以任务记录为依据，两版共用经核实的情节底稿。发现纪事版存在事实或顺序错误时，同步修订两版，并保留核对依据。原作没有说出的内心与台词，保留为未知。修辞只改变叙述方式，不添加设定或改写事件结果。事实与顺序的修订见[逻辑复核记录](epic-logic-review.md)，其后的动机、身份与跨版本承接修订见[首次阅读视角记录](first-reader-followup.md)。

## 样章试读

当前样章的开篇与风灾段落：

> 双子结伴，游历诸多世界。离开提瓦特之际，陌生的神明拦在前方。交锋之后，双子失散。一人遭神明掳去，一人失去力量，沉入漫长的梦乡。
>
> 城墙之内，是世人所称的自由之城；城墙之上，风暴紧随而来。「风魔龙」掠过城邦，旅人被卷上高空。风曾在神像前回应，如今又托起迎战的身影。旅人借风击退巨龙，重返城中。

事实底稿见 [1.0 纪事版中的序章第一幕](../story-summaries/1.x/1.0-序章第1至3幕与第一章第1至2幕-捕风的异乡人至辞行久远之躯.md)。完整样章续写了风神像共鸣、低语森林的相遇、安柏引路与赠翼、蒙德风灾和庙宇调查，止于序章第一幕当时已知的信息。

## 后续七国风格

七国可在统一叙事方法之上，各自选用具体文学传统与参考作品，调整节奏、称谓和意象。例如，蒙德可以研究日耳曼英雄叙事，璃月可以研究祭歌与古代神话书写。各国的参考文本与文化映射仍需逐一检索、试写和确认；当前全部篇章采用同一套已确认的史诗散文风格。
